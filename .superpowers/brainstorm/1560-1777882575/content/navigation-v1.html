MVP 导航结构选型

基于设计方案 v1.3：优先完成 Android 体验，并为后端 API 预留对接点

MVP 核心入口

首页、市场、交易/持仓、新闻、我的（资产/信用/设置）

A

底部 Tab（5 栏）

Home / Market / Trade / News / Me

优点

  • Android 上手最快
  • 主流程触达成本低

注意

  • 二级页面跳转层级要控制
B

侧边栏（偏 Web/宽屏）

左侧主导航 + 右侧内容区

优点

  • 信息密度更高
  • 更适合后台/管理视图

注意

  • 移动端需要折叠/抽屉适配
C

混合：底部 Tab + “更多”聚合

Home / Market / Trade / News + More（资产/银行/IPO/信用）

优点

  • 主流程更聚焦
  • 扩展模块不挤占主导航

注意

  • 需要定义“更多”内的信息架构
