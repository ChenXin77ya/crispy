# 资本纪元：交易所大亨

## 06. 项目脚手架与初始化命令

本文档用于帮助你把开发包真正落地成工程目录。

目标：

- 初始化 Flutter 工程
- 初始化 Rust 工程
- 启动 PostgreSQL
- 建立最小开发目录

---

## 一、推荐工程目录

建议在实际开发目录使用如下结构：

```text
capital-epoch/
  mobile_web_app/
  backend_api/
  infra/
    docker-compose.yml
    .env.example
  docs/
```

说明：

- `mobile_web_app`：Flutter 工程
- `backend_api`：Rust 服务端
- `infra`：本地开发基础设施
- `docs`：复制当前开发包文档

---

## 二、Flutter 初始化

## 2.1 创建工程

```bash
flutter create mobile_web_app
```

## 2.2 开启 Web 支持

```bash
flutter config --enable-web
```

## 2.3 安装建议依赖

进入 `mobile_web_app` 后：

```bash
flutter pub add go_router flutter_riverpod dio freezed_annotation json_annotation shared_preferences
flutter pub add --dev build_runner freezed json_serializable
```

## 2.4 推荐先创建的目录

```text
lib/
  app/
  core/
  features/
  shared/
```

---

## 三、Rust 初始化

## 3.1 创建工程

```bash
cargo new backend_api
```

## 3.2 安装建议依赖

在 `backend_api/Cargo.toml` 中建议加入：

```toml
[dependencies]
axum = "0.8"
tokio = { version = "1", features = ["full"] }
serde = { version = "1", features = ["derive"] }
serde_json = "1"
sqlx = { version = "0.8", features = ["runtime-tokio-rustls", "postgres", "uuid", "chrono", "migrate"] }
uuid = { version = "1", features = ["v4", "serde"] }
chrono = { version = "0.4", features = ["serde"] }
tracing = "0.1"
tracing-subscriber = { version = "0.3", features = ["env-filter"] }
thiserror = "2"
anyhow = "1"
tower-http = { version = "0.6", features = ["cors", "trace"] }
jsonwebtoken = "9"
argon2 = "0.5"
```

## 3.3 推荐目录

```text
src/
  main.rs
  app/
  config/
  router/
  handlers/
  services/
  repos/
  models/
  domains/
  jobs/
  utils/
```

---

## 四、PostgreSQL 启动

## 4.1 推荐方式

建议本地开发先使用 Docker。

你可以直接使用同目录下提供的：

- `docker-compose.yml`
- `.env.example`

## 4.2 启动命令

在 `infra` 目录下执行：

```bash
docker compose up -d
```

## 4.3 连接信息

默认建议：

- 数据库：`capital_epoch`
- 用户：`capital_epoch`
- 密码：`capital_epoch`
- 端口：`5432`

---

## 五、开发启动顺序

## 5.1 第一步：起数据库

```bash
docker compose up -d
```

## 5.2 第二步：执行建表 SQL

将 `02_数据库初始化草案.sql` 导入数据库。

例如：

```bash
psql postgresql://capital_epoch:capital_epoch@localhost:5432/capital_epoch -f 02_数据库初始化草案.sql
```

## 5.3 第三步：启动 Rust 后端

```bash
cargo run
```

## 5.4 第四步：启动 Flutter Android/Web

Android：

```bash
flutter run
```

Web：

```bash
flutter run -d chrome
```

---

## 六、最小启动目标

第一天建议只完成以下事情：

1. Flutter 工程跑起来
2. Rust 服务返回 `/health`
3. PostgreSQL 能连通
4. Flutter 能请求 `/health`

只要这四件事通了，后面就能稳定往下写。

---

## 七、建议的第一批代码文件

## Flutter

建议先建立：

- `main.dart`
- `app/app.dart`
- `app/router.dart`
- `features/home/presentation/home_page.dart`
- `features/stock/presentation/stock_detail_page.dart`

## Rust

建议先建立：

- `main.rs`
- `app/state.rs`
- `router/mod.rs`
- `handlers/health.rs`
- `handlers/auth.rs`
- `handlers/portfolio.rs`

---

## 八、建议的第一批接口

优先开发：

1. `GET /health`
2. `POST /api/v1/auth/register`
3. `POST /api/v1/auth/login`
4. `GET /api/v1/auth/me`
5. `GET /api/v1/portfolio/summary`
6. `GET /api/v1/market/home`
