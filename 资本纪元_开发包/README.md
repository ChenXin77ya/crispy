# 资本纪元：交易所大亨

## 开发包总览

这套开发包用于把现有策划和执行层文档推进到“可以正式开工”的状态，技术栈固定为：

- 前端：`Flutter`
- 后端：`Rust`
- 数据库：`PostgreSQL`
- 运行平台：`Android`、`Web`

适用场景：

- 你自己主导开发
- 使用 `Trae / Solo` 协助编码
- 先完成可运行的 MVP，再逐步补复杂规则

## 当前建议开发目标

第一阶段不要试图一次做完整金融沙盒，而是先做一个可玩的 MVP：

### MVP 必须包含

- 账户系统
- 资产总览
- 基础股票交易
- 系统基金
- 新闻快讯
- IPO展示与基础申购
- 个人信用分展示

### MVP 暂缓

- 复杂银行挤兑
- 高级期货
- 多层承销
- 复杂做市
- 完整舆情对战

## 技术路线建议

### 前端

Flutter 采用：

- `go_router` 做路由
- `riverpod` 做状态管理
- `dio` 做网络层
- `freezed + json_serializable` 做模型

### 后端

Rust 建议采用：

- `axum` 作为 Web 框架
- `sqlx` 作为数据库访问层
- `tokio` 作为异步运行时
- `serde` 做序列化
- `uuid`、`chrono` 处理主键和时间

### 数据库

PostgreSQL 负责：

- 交易业务主数据
- 用户资产与持仓
- 银行、IPO、新闻、信用等模块核心数据

---

## 开发时的关键原则

1. 先把核心链路打通，再补细节
2. 先做“能解释清楚”的系统，再做“更真实”的系统
3. 先做同步查询接口，再补后台任务和实时推送
4. 先让 Android 正常玩通，再适配 Web 的布局和交互
